## 문제. 최근접 점 쌍 웹 앱

**완전 탐색**(brute force) 접근과 **분할 정복** 알고리즘을 비교하고, 결과를 2차원 캔버스에 시각화하는 **최근접 점 쌍**(closest pair of points) 웹 앱을 만든다.

- **백엔드:** Python (FastAPI 또는 Flask)
- **프런트엔드:** HTML, CSS, JavaScript (Canvas)

### 1. 최근접 점 쌍 알고리즘

2차원 평면의 점 n개에서 최근접 점 쌍을 찾는 **두 가지 접근**을 구현한다.

| 접근 | 방법 | 복잡도 |
|:-----|:-----|:-----|
| 완전 탐색 | n(n−1)/2개의 모든 쌍을 검사한다 | O(n²) |
| 분할 정복 | x좌표로 나누고, 재귀적으로 풀고, 중간 띠(strip)를 검사한다 | O(n log² n) |

*표 1. 구현할 두 가지 접근*

**분할 정복 전략:**

1. 점들을 x좌표로 정렬한다.
2. 왼쪽(LEFT)과 오른쪽(RIGHT) 두 절반으로 나눈다.
3. 각 절반에서 최근접 점 쌍을 재귀적으로 찾고, 그 거리를 d로 둔다.
4. 중간 띠(분할선에서 거리 d 이내에 있는 점들)를 검사한다.
5. 전체에서 가장 가까운 쌍을 반환한다.

### 2. 웹 인터페이스

- 무작위 점 n개를 흩뿌리는 **"Generate Random"** 버튼을 둔다(n은 사용자가 정한다).
- **"Find Closest Pair"** 를 누르면 두 알고리즘을 모두 실행한다.
- **2차원 캔버스**에 다음을 표시한다.
  - 모든 점을 작은 점으로 그린다.
  - **최근접 점 쌍**을 강조하고 두 점을 선으로 잇는다.
- 완전 탐색과 분할 정복의 **실행 시간**과 **속도 향상 비율**(speedup ratio)을 보여 준다.

### 3. API 엔드포인트

| 메서드 | 엔드포인트 | 설명 |
|:-----|:-----|:-----|
| `POST` | `/closest-pair` | 두 방법으로 최근접 점 쌍을 찾고 결과와 실행 시간을 반환 |
| `POST` | `/generate` | 무작위 2차원 점 n개를 생성 |
| `GET` | `/` | 프런트엔드 페이지 제공 |

*표 2. 구현할 API 엔드포인트*
