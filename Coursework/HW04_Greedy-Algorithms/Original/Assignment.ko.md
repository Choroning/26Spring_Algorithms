## 문제. 강의실 예약 웹 앱

**그리디 활동 선택**(greedy activity selection) 알고리즘으로 한 강의실에 서로 겹치지 않는 행사를 최대한 많이 배정하는 **강의실 예약 시스템** 웹 앱을 만든다.

- **백엔드:** Python (FastAPI 또는 Flask)
- **프런트엔드:** HTML, CSS, JavaScript

### 1. 그리디 활동 선택

다음과 같은 **활동 선택 알고리즘**을 구현한다.

- 입력: 예약 요청의 목록이며, 각 요청은 **시작 시간**과 **종료 시간**을 가진다.
- **종료 시간**으로 정렬한다.
- 서로 겹치지 않는 행사를 그리디하게 선택한다.
- 출력: 수용할 수 있는 예약의 **최대 집합**

### 2. 웹 인터페이스

- 사용자는 행사 이름, 시작 시간, 종료 시간을 입력하여 **예약을 추가**할 수 있다.
- 예시 데이터(예: 무작위 행사 15개)를 만드는 **"Generate Random"** 버튼을 둔다.
- **"Schedule"** 을 누르면 그리디 알고리즘을 실행한다.
- 다음을 표시한다.
  - 모든 요청(회색)과 선택된 행사(강조 표시)를 보여 주는 **타임라인 시각화**
  - 전체 요청 수 대비 **선택된 행사의 수**
  - 그리디 선택 순서의 **단계별 추적**

### 3. API 엔드포인트

| 메서드 | 엔드포인트 | 설명 |
|:-----|:-----|:-----|
| `POST` | `/schedule` | 활동 선택을 실행하고 선택된 행사를 반환 |
| `POST` | `/generate` | 무작위 예약 요청을 생성 |
| `GET` | `/` | 프런트엔드 페이지 제공 |

*표 1. 구현할 API 엔드포인트*
