## 문제. 표절 검사 웹 앱

두 문서를 비교하고 **최장 공통 부분 수열**(Longest Common Subsequence, LCS) 알고리즘(동적 프로그래밍)으로 유사도를 계산하는 **표절 검사기** 웹 앱을 만든다.

- **백엔드:** Python (FastAPI 또는 Flask)
- **프런트엔드:** HTML, CSS, JavaScript

### 1. LCS 기반 유사도 분석

동적 프로그래밍으로 **LCS 알고리즘**을 구현한다.

- 입력된 두 텍스트에 대해 **DP 표**를 만든다.
- **역추적**(backtrack)으로 LCS를 찾는다.
- **유사도 점수**를 `LCS length / max(len(A), len(B)) * 100%`로 계산한다.
- **diff 보기**를 만든다. 각 부분을 일치(matched), 추가(added), 삭제(removed)로 표시한다.

### 2. 웹 인터페이스

- 문서 A와 문서 B를 입력하는 두 개의 **텍스트 영역**을 둔다.
- 표절 분석을 실행하는 **"Check"** 버튼을 둔다.
- 다음을 표시한다.
  - **유사도 점수**(백분율)
  - **LCS 길이**와 실제 LCS 문자열
  - **색으로 구분한 diff 보기:** 일치(회색), 삭제(빨간색), 추가(초록색)

### 3. API 엔드포인트

| 메서드 | 엔드포인트 | 설명 |
|:-----|:-----|:-----|
| `POST` | `/check` | 두 텍스트를 비교하고 유사도 점수와 diff를 반환 |
| `GET` | `/` | 프런트엔드 페이지 제공 |

*표 1. 구현할 API 엔드포인트*
