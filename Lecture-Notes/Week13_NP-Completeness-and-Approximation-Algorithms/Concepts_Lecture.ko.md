## 1. 문제의 복잡도 분류

### 1.1 NP-완비성 이론이 중요한 이유

상사가 효율적인 알고리즘이 떠오르지 않는 문제를 맡긴 상황을 생각한다. 가능한 답변은 세 가지이다.

- **시나리오 1:** *"효율적 알고리즘을 못 찾겠습니다. 제가 똑똑하지 못해서요."* 이 답변은 부끄러운 고백일 뿐이다.
- **시나리오 2:** *"효율적 알고리즘을 못 찾겠습니다. 그런 알고리즘이 존재하지 않기 때문입니다."* 가장 강력한 답변이지만 비존재를 증명하기는 어렵다.
- **시나리오 3 (NP-Complete):** *"효율적 알고리즘을 못 찾았지만, 50년 넘게 수천 명의 뛰어난 사람들도 관련된 수백 개 문제에 대해 마찬가지였습니다."* 직업적으로 방어할 수 있는 답변이다.

> **핵심:** NP-완비성 이론의 요점은 시나리오 1을 시나리오 3으로 격상시키는 것이다. 이 이론은 정확한 다항 시간 해법의 탐색을 멈추고 휴리스틱이나 근사로 선회할 *정당하고* *이론적 기반이 있는* 근거를 제공한다.

### 1.2 문제의 분류

```text
┌──────────────────────────────────────────────────────────┐
│                   ALL PROBLEMS                            │
│                                                          │
│  ┌─────────────────────────────────────────────────────┐ │
│  │  Solvable (결정 가능)                                │ │
│  │                                                     │ │
│  │  ┌───────────────────────────────────────────────┐  │ │
│  │  │  Tractable: 다항 시간                          │  │ │
│  │  │  - Shortest Path, MST, Sorting, ...           │  │ │
│  │  │  - 시간: 어떤 상수 k 에 대해 O(n^k)             │  │ │
│  │  └───────────────────────────────────────────────┘  │ │
│  │  ┌───────────────────────────────────────────────┐  │ │
│  │  │  Intractable: 알려진 다항 알고리즘 없음        │  │ │
│  │  │  *** NP-Complete 문제들이 여기 ***              │  │ │
│  │  │  - SAT, TSP, Vertex Cover, Clique, ...        │  │ │

│  │  └───────────────────────────────────────────────┘  │ │
│  │  ┌───────────────────────────────────────────────┐  │ │

│                                                          │
│  ┌─────────────────────────────────────────────────────┐ │
│  │  Unsolvable (결정 불가능)                            │ │
│  │  - 정지 문제, Hilbert 10번째 문제 등                  │ │
│  └─────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────┘
```

*그림 1. 결정 가능성과 시간 복잡도에 따른 문제의 분류*

> **참고:** **중요한 구분.** intractable과 unsolvable은 같지 않다(intractable ≠ unsolvable). Intractable 문제는 *알고리즘이 있지만* 그 알고리즘이 다항 시간에 실행되지 않을 뿐이다. Unsolvable 문제는 *알고리즘이 전혀 없다*. 정지 문제는 시간을 얼마나 주더라도 결정할 수 없다.

### 1.3 다루기 쉬운 시간 = 다항 시간

**다항 시간:** 입력 크기가 $n$일 때 수행 시간이 어떤 상수 $k$에 대해 $O(n^k)$로 제한된다.

| 다루기 쉬움 (다항)        | 다루기 어려움 (초다항)               |
|---------------------------|--------------------------------------|
| $O(\log n)$               | $O(2^n)$ (지수)                       |
| $O(n)$                    | $O(n!)$ (팩토리얼)                    |
| $O(n \log n)$             | $O(n^n)$                              |
| $O(n^2), O(n^3)$          |                                       |

*표 1. 다루기 쉬운 시간 복잡도와 다루기 어려운 시간 복잡도의 예*

> **참고:** **관례.** 문제를 효율적으로 풀 수 있다는 것은 다항 시간 알고리즘이 존재한다는 뜻이다. 이 관례를 Cobham-Edmonds 논제(Cobham-Edmonds thesis)라 한다. 경계를 일부러 거칠게 긋지만, 다항 시간 클래스는 계산 모델이 바뀌어도 안정적이므로 이론적 목적에 적합하다.

### 1.4 유명한 NP-완비 문제들

다음은 이후 절의 동기가 되는 대표적인 문제들이다. 각 문제는 NP-Complete이며, 증명은 뒤에서 다루거나 이들 중 하나로부터의 환원으로 얻는다.

**SAT (Boolean Satisfiability).** Boolean 변수들이 절(clause) 안에서 OR($\lor$)로 연결되고 절들이 AND($\land$)로 연결되어 있을 때, 모든 절을 만족하는 할당을 찾는다.

$$(\overline{w} \lor x) \land (w \lor y) \land (\overline{x} \lor \overline{y} \lor z)$$

- 위 식은 $w = T, x = T, y = F$이면 $z$의 값과 관계없이 만족된다.
- $(x) \land (\overline{x})$는 **만족 불가능**하다.
- SAT는 **NP-Complete임이 증명된 최초의 문제**이다(Cook, 1971; 독립적으로 Levin, 1973).

**Subset Sum.** 정수 집합 $S$와 목표 $K$가 주어졌을 때, 합이 정확히 $K$인 $S$의 부분집합이 있는가?
- $S = \{20, 30, 40, 80, 90\}$, $K = 200$이면 $\{30, 80, 90\}$이 그런 부분집합이다.

**Partition.** $S$가 주어졌을 때 $S$를 합이 같은 두 부분집합으로 나눌 수 있는가?
- $S = \{20, 30, 40, 80, 90\}$(총합 260)은 $\{20, 30, 80\}$과 $\{40, 90\}$(각 130)으로 나눌 수 있다.
- Subset Sum은 Partition으로 다항 시간에 환원된다.

**0-1 Knapsack (결정 버전).** 용량 $C$와, 무게가 $w_i$이고 가치가 $v_i$인 아이템들이 주어진다. 총 무게가 $C$ 이하이고 총 가치가 $K$ 이상인 부분집합이 존재하는가?

| 아이템 | 무게  | 가치 |
|--------|-------|------|
| 1      | 12 kg | 20   |
| 2      | 8 kg  | 10   |
| 3      | 6 kg  | 15   |
| 4      | 5 kg  | 25   |

*표 2. 0-1 Knapsack 예시의 아이템별 무게와 가치*

- $C = 20$일 때 아이템 $\{2, 3, 4\}$는 무게가 19, 가치가 50이다.
- **DP가 있는데도 NP-Complete인 이유:** 6주차의 DP 해법은 $O(nC)$이다. 하지만 $C$는 $\log C$비트로 인코딩되므로 이 DP는 *유사 다항(pseudo-polynomial)* 시간이다. $C$의 *값*에 대해서는 다항이지만 *비트 길이*에 대해서는 지수 시간이다.

**그래프 문제들:**

- **Vertex Cover.** 모든 간선에 닿는 최소 정점 집합을 찾는다.
- **Independent Set.** 서로 인접하지 않은 정점들로 이루어진 최대 정점 집합을 찾는다.
- **Clique.** 최대 완전 부분 그래프를 찾는다.
- **Graph Coloring.** 인접한 정점이 서로 다른 색을 갖도록 하는 최소 색 수를 찾는다.
- **Longest Path.** 길이가 $K$ 이상인 단순 $s \to t$ 경로가 있는가? 이 문제는 놀랍게도 NP-Complete이다(Shortest Path는 P에 속한다).
- **Set Cover.** 합집합이 전체 집합과 같아지는 최소 개수의 부분집합을 찾는다.

> **참고:** **아름다운 관계.** 그래프 $G = (V, E)$에서 $S$가 vertex cover일 필요충분조건은 $V \setminus S$가 independent set인 것이다. $G$의 clique은 보완 그래프 $\overline{G}$의 independent set에 대응한다. 많은 NP-완비 문제가 이런 자명한 쌍대성의 양쪽에 놓여 있다.

**투어 스타일 문제들:**

- **TSP.** 가중 완전 그래프에서 최단 Hamilton 사이클을 찾는다.
- **Hamiltonian Cycle.** 그래프에 Hamilton 사이클이 *하나라도* 있는가? 이 문제는 TSP로 환원된다. 원래 그래프의 간선에 가중치 1을, 원래 그래프에 없는 간선에 큰 가중치를 주면 된다(2.5절).
- **Bin Packing.** $n$개 아이템을 용량 $C$인 빈 최소 개수에 패킹한다.
- **Job Scheduling.** $n$개 작업을 $m$개의 동일한 기계에 할당해 **makespan**을 최소화한다. Makespan은 가장 늦게 끝나는 기계의 완료 시간이며, 가장 늦게 끝나는 작업의 완료 시간이기도 하다.

### 1.5 결정 문제 vs 최적화 문제

| 측면                          | 결정 문제                                    | 최적화 문제                  |
|-------------------------------|----------------------------------------------|------------------------------|
| **답**                        | Yes 또는 No                                  | 최고의 해                    |
| **예시 (TSP)**                | 길이가 $K$ 이하인 투어가 있는가?             | 최단 투어의 길이는 얼마인가? |
| **예시 (Shortest Path)**      | 길이가 100 이하인 경로가 있는가?             | 최단 경로의 길이는 얼마인가? |

*표 3. 결정 문제와 최적화 문제의 비교*

**NP-완비성이 결정 문제로 기술되는 이유:**

- 환원 기구는 답이 Yes/No일 때 가장 깔끔하다.
- 최적화 버전은 결정 버전보다 **적어도 같은 만큼 어렵다**. 최단 투어의 길이를 구할 수 있으면 그 길이가 $K$ 이하인지는 바로 답할 수 있다.
- 그러므로 결정 버전의 어려움은 최적화 버전의 어려움을 *함의*하지만, 역방향은 깔끔하게 성립하지 않는다. 따라서 어려움을 결정 형식으로 진술하는 것이 가장 강하고 빈틈없는 주장이다.

## 2. P, NP, 그리고 NP-완비성 이론

### 2.1 클래스 P

**P**는 **결정적(deterministic) 알고리즘**으로 **다항 시간**에 풀 수 있는 결정 문제의 집합이다.

- 크기가 $n$인 임의의 입력에 대해, 어떤 고정된 $k$에 대해 $O(n^k)$ 시간에 Yes 또는 No를 출력한다.

**P의 예시:**

- 그래프가 연결되어 있는가? BFS나 DFS로 $O(V + E)$에 답한다.
- 간선 가중치가 음수가 아닐 때, $u$에서 $v$까지 길이가 $K$ 이하인 최단 경로가 있는가? Dijkstra 알고리즘으로 $O(V^2)$ 또는 $O((V+E) \log V)$에 답한다.
- $n$개 숫자를 $T$회 이하의 비교로 정렬할 수 있는가? 병합 정렬로 $O(n \log n)$에 정렬한다.
- 가중치가 $K$ 이하인 MST가 있는가? Kruskal 알고리즘으로 $O(E \log E)$에 답한다.

> **참고:** 1~12주차에서 다룬 알고리즘은 대부분 **P**에 속하는 문제를 다항 시간에 푼다. 예외로 6주차의 0-1 Knapsack DP는 $O(nC)$의 유사 다항 시간 알고리즘이며, 0-1 Knapsack의 결정 버전은 NP-Complete이다(1.4절).

### 2.2 클래스 NP

**NP**는 **N**ondeterministic **P**olynomial time(비결정적 다항 시간)의 약자이다.

결정 문제가 NP에 속할 조건은 **Yes certificate**(제안된 해)가 주어졌을 때 certificate의 유효성을 **다항 시간에 검증**할 수 있는 것이다.

> **주의:** **흔한 혼동.** NP는 non-polynomial의 약자가 **아니다**. *Nondeterministic polynomial*의 약자로, 이상적인 **비결정적 기계**가 다항 시간에 풀 수 있는 문제의 클래스이다. 동등하게, Yes 답을 다항 시간에 **검증**할 수 있는 문제들의 집합이다.

> **참고:** **비결정적(nondeterministic)의 의미.** 역사적 정의에서는 기계가 매 단계 여러 동작 중 하나를 추측하고, 추측의 연속 중 *하나라도* Yes로 이어지면 입력을 받아들인다고 상상한다. 이는 사실상 모든 certificate를 병렬로 시도하는 것과 같다. 이 정리본은 **동등한 검증기/certificate 정의**를 사용한다. 즉, certificate가 주어지면 그것을 다항 시간에 확인한다. 두 정의가 같은 클래스를 설명하므로 여기서 비결정적이라는 말은 **역사적 명칭**일 뿐이다. NP는 다항 시간에 검증 가능한 문제의 클래스로 이해하면 된다.

> **[계산이론]** 계산이론은 결정 문제를 문자열의 집합인 언어로 부호화하고, P를 결정적 튜링 기계가, NP를 비결정적 튜링 기계가 다항 시간에 받아들이는 언어의 클래스로 정의한다. 이 정리본이 쓰는 검증기 정의는 이 형식 정의와 같은 클래스를 주며, 1.2절의 결정 불가능성과 2.10절의 Cook 정리도 같은 튜링 기계 모델 위에서 엄밀하게 진술된다.

**직관적 특성화:**

- **P**는 빠르게 **풀** 수 있는 문제의 클래스이다.
- **NP**는 빠르게 **검증**할 수 있는 문제의 클래스이다.

**NP의 예시:**

- **Hamiltonian Cycle:** certificate는 정점 수열이다. 모든 정점이 정확히 한 번 나타나고 연속한 쌍이 간선으로 연결되는지 확인하면 되므로 검증은 $O(V)$이다.
- **SAT:** certificate는 True/False 할당이다. 할당을 대입한 뒤 각 절을 확인하면 되므로, 절이 $m$개이고 절마다 리터럴이 $k$개이면 검증은 $O(m \cdot k)$이다.
- **Subset Sum:** certificate는 부분집합이다. 원소를 합산해 $K$와 비교하면 되므로 검증은 $O(n)$이다.

> **핵심:** 문제가 NP에 속함을 보이는 것은 보통 쉬우며, NP-완비성 증명에서 사실상 형식적인 절차이다. 어려운 부분은 NP-Hard임을 보이는 것이다.

### 2.3 P vs NP: 100만 달러짜리 질문

```text
  가능성 (a): P ≠ NP                      가능성 (b): P = NP
       (강하게 믿는 쪽)                          (충격적)

  ┌──────────────────────┐                ┌──────────────────────┐
  │         NP           │                │                      │
  │   ┌──────────────┐   │                │       P = NP         │
  │   │      P       │   │                │                      │
  │   └──────────────┘   │                │  NP의 모든 문제가     │
  │                      │                │  다항 시간에          │
  └──────────────────────┘                │  풀림                 │
                                          └──────────────────────┘
```

*그림 2. P ≠ NP와 P = NP의 두 가능성*

- $P \subseteq NP$는 자명하다. 다항 시간에 풀 수 있으면 다시 실행해서 다항 시간에 검증할 수 있기 때문이다.
- $P = NP$인지 $P \neq NP$인지는 **컴퓨터 과학에서 가장 유명한 미해결 문제**이다.
- **Clay Millennium Prize**는 어느 쪽이든 증명하면 100만 달러의 상금을 준다.
- 연구자들의 압도적인 합의는 $P \neq NP$이지만, 이는 *증명되지 않았다*.

> **참고:** **왜 누구나 관심을 갖는가.** $P = NP$라면 NP에 속하는 모든 문제(인수분해, SAT, TSP, vertex cover, 그리고 모든 NP-Complete 문제)를 다항 시간에 풀 수 있게 된다. 현재의 암호학은 안전성의 근거를 잃는다. 계획, 일정, 신약 개발 등 모든 것을 최적화할 수 있다. $P \neq NP$를 증명하는 데 평생을 바친 연구자가 많지만 아무도 성공하지 못했다.

### 2.4 다항 시간 환원

다항 시간 환원은 이 주제에서 가장 중요한 구성이다.

![그림 3. 다항 시간 환원 다이어그램](../../images/Week13_ch34_p05.png)

*그림 3. 다항 시간 환원 다이어그램*

**정의.** 다음을 만족하는 함수 $f$가 존재하면 문제 $A$가 문제 $B$로 **환원된다**고 하고 $A \leq_P B$로 쓴다.

1. $f$는 $A$의 모든 인스턴스 $\alpha$를 $B$의 인스턴스 $f(\alpha) = \beta$로 **다항 시간에** 변환한다.
2. $\alpha$가 $A$의 Yes 인스턴스일 **필요충분조건**은 $f(\alpha)$가 $B$의 Yes 인스턴스인 것이다.

**결론:** $A \leq_P B$이고 $B$를 다항 시간에 풀 수 있으면 $A$도 다항 시간에 풀 수 있다. $A$의 입력을 $B$로 변환해 $B$의 알고리즘에 물어보면 되기 때문이다.

**대우(contrapositive)** 가 NP-완비성의 핵심이다. $A$가 *어렵고* $A \leq_P B$이면 $B$도 *어렵다*. $B$를 효율적으로 풀 수 있다면 $A$도 효율적으로 풀 수 있어 모순이기 때문이다.

### 2.5 환원 예시

**예시 1 (수론, 장난감 예시):**

- **문제 1:** 정수 $x = x_1 x_2 \dots x_n$(자릿수 표현)이 3으로 나누어지는가?
- **문제 2:** $x_1 + x_2 + \dots + x_n$이 3으로 나누어지는가?

모든 입력에 대해 두 문제의 답은 같다(자릿수 합 판정법). 변환은 자릿수를 추출해 합산하는 것이며 $O(n)$이다. 문제 2는 자명하게 쉬우므로 문제 1도 쉽다. 즉 $\text{문제 1} \leq_P \text{문제 2}$이다.

**예시 2 (HAM-CYCLE $\leq_P$ TSP):**

- **HAM-CYCLE:** 그래프 $G = (V, E)$가 Hamilton 사이클을 가지는가?
- **TSP (결정):** 가중 완전 그래프 $G'$과 한계 $K$가 주어졌을 때, $G'$이 가중치 합이 $K$ 이하인 Hamilton 사이클을 가지는가?

**변환:** HAM-CYCLE의 입력 $G$를 받아 같은 정점 위의 완전 그래프 $G'$을 구성한다. 간선 가중치는 다음과 같다.

```text
  HAM-CYCLE 인스턴스           TSP 인스턴스
  (4 정점, 5 간선)              (완전, 6 간선 모두 가중)

    a --- b                      a --1-- b
    |   / |        ═══>          |1\∞ /1 |1
    |  /  |                      |  \/   |
    c --- d                      c --1-- d

  G의 간선        → 가중치 1                K = |V|
  G에 없는 간선   → 가중치 ∞ (또는 2|V|)
```

*그림 4. HAM-CYCLE 인스턴스를 TSP 인스턴스로 바꾸는 변환*

- 그림의 $G$에 없는 간선은 $a$와 $d$를 잇는 간선 하나뿐이므로, $G'$에서는 이 간선의 가중치만 ∞(또는 $2|V|$)이고 나머지 다섯 간선의 가중치는 1이다.
- $G$가 Hamilton 사이클을 가질 **필요충분조건**은 $G'$이 가중치 $|V|$ 이하인 투어를 가지는 것이다.
- 변환은 $O(V^2)$이므로 다항 시간이다.

따라서 $\text{HAM-CYCLE} \leq_P \text{TSP}$이다. HAM-CYCLE이 NP-Complete임이 알려져 있으므로 TSP는 NP-Hard이다.

### 2.6 NP-Hard와 NP-Complete의 정의

**NP-Hard.** NP의 **모든** 문제가 $A$로 환원되면 $A$는 NP-Hard이다.

$$\text{모든 } L \in NP \text{ 에 대해: } \quad L \leq_P A.$$

말로 하면, $A$는 **NP의 모든 문제만큼 어렵다**. 중요한 점은 $A$ 자체가 NP에 속할 필요는 **없다**는 것이다. 정지 문제는 NP-Hard이지만 결정 불가능하므로 NP 밖에 있다.

![그림 5. P, NP, NPC 벤 다이어그램](../../images/Week13_ch34_p23.png)

*그림 5. P, NP, NPC 벤 다이어그램*

**NP-Complete.** 다음 두 조건을 만족하면 $A$는 NP-Complete이다.

1. $A \in NP$이다(Yes certificate를 다항 시간에 검증할 수 있다). **그리고**
2. $A$가 NP-Hard이다.

```text
  ┌──────────────────────────────────────────────┐
  │                  NP-Hard                      │
  │                                               │
  │       ┌───────────────────────────────┐       │
  │       │            NP                 │       │
  │       │                               │       │
  │       │    ┌───────────────────┐      │       │
  │       │    │        P          │      │       │
  │       │    └───────────────────┘      │       │
  │       │                               │       │
  │       │          NP-Complete           │       │
  │       │        (SAT, TSP, Clique,      │       │
  │       │      Vertex Cover, 3-SAT, …)   │       │
  │       └───────────────────────────────┘       │
  │                                               │
  │   NP-Hard 이지만 NP가 아님:                    │
  │   (정지 문제, 일반화된 체스, …)                  │
  └──────────────────────────────────────────────┘

  * P가 부분집합으로 나타나는 것은 P ≠ NP 가정 하 (널리 믿어짐).
```

*그림 6. P, NP, NP-Complete, NP-Hard의 관계를 나타낸 개략도*

- **NP-Complete = NP ∩ NP-Hard**이다.
- NP-Complete 문제는 정의상 NP-Hard이기도 하므로 NP-Hard라 불러도 맞지만, NP에 속한다는 정보가 빠지므로 덜 구체적이다.
- 그림의 일반화된 체스는 EXPTIME-완비 문제이므로 NP-Hard이다. 그러나 NP ≠ EXPTIME이 증명되지 않았으므로, 일반화된 체스가 NP 밖에 있다는 것은 널리 믿어질 뿐 증명되지 않았다.

> **참고:** 그림 6은 NP 전체를 NP-Hard 상자 안에 그렸지만, 실제로 두 클래스는 교집합인 NP-Complete에서만 겹친다. $P \neq NP$이면 P에 속하는 문제는 NP-Hard가 아니다.

### 2.7 NP-완비성 증명 방법

**2단계 레시피.**

**Step 1:** $A \in NP$임을 증명한다.
- $A$의 Yes certificate를 다항 시간에 검증하는 알고리즘을 기술한다.
- 보통 몇 줄이면 되는 쉬운 부분이다.

**Step 2:** $A$가 NP-Hard임을 증명한다.
- 알려진 NP-Hard(또는 NP-Complete) 문제 $C$를 고른다.
- 다항 시간 환원 $C \leq_P A$를 구성한다.
- **양방향**으로 Yes/No가 보존됨을 증명한다.

```text
  다항 시간 환원
    α (C 의 인스턴스) ────f────> β = f(α) (A 의 인스턴스)
                                          │
                                  A 의 알고리즘
                                          │
                                          ▼
       Yes  ◄────────────────────────► Yes
       No   ◄────────────────────────► No

  "A 를 다항 시간에 풀 수 있다면,
   C 도 다항 시간에 풀 수 있다."
```

*그림 7. 다항 시간 환원에서 Yes/No 답이 보존되는 구조*

$\leq_P$의 추이성에 의해, *모든* NP 문제가 $C$로 환원되고 $C$가 $A$로 환원되므로 *모든* NP 문제가 $A$로 환원된다. 따라서 $A$는 NP-Hard이다. $A \in NP$와 합치면 $A$는 NP-Complete이다.

### 2.8 증명: LONGEST-PATH는 NP-Complete

**정의.**

- **HAM-PATH-2-POINTS:** $G = (V, E)$와 정점 $s, t$가 주어졌을 때, $G$가 $s$에서 $t$로 가는 Hamilton 경로를 가지는가? 이 문제는 *NP-Complete임이 알려져 있다*.
- **LONGEST-PATH:** 가중 그래프 $G = (V, E)$, 정점 $s, t$, 상수 $K$가 주어졌을 때, $s$에서 $t$로 가는 총 가중치가 $K$ 이상인 단순 경로가 존재하는가?

**Step 1: LONGEST-PATH $\in$ NP.**
- *Certificate:* $s$에서 $t$로 가는 경로를 이루는 정점 수열이다.
- *검증:* 수열이 $s$에서 시작해 $t$에서 끝나고 정점이 반복되지 않는지, 연속한 쌍이 $E$의 간선인지 확인한 뒤, 가중치를 합산해 합이 $K$ 이상인지 확인한다.
- *시간:* $O(|V|)$이다.

**Step 2: HAM-PATH-2-POINTS $\leq_P$ LONGEST-PATH.**

*변환.* HAM-PATH-2-POINTS 인스턴스 $G = (V, E)$와 끝점 $s, t$가 주어지면 다음과 같이 한다.
- $G$를 그대로 복사하고 모든 간선에 **가중치 1**을 할당한다.
- $K = |V| - 1$로 둔다.

```text
  HAM-PATH-2-POINTS 인스턴스        LONGEST-PATH 인스턴스

  s --- a --- b                     s -1- a -1- b
  |           |          ═══>       |           |
  c --- d --- t                     c -1- d -1- t

  "Hamilton s→t 경로?"              "가중치 ≥ |V|-1 인 단순 s→t 경로?"
```

*그림 8. HAM-PATH-2-POINTS 인스턴스를 LONGEST-PATH 인스턴스로 바꾸는 변환*

**정방향.** Hamilton $s \to t$ 경로는 $|V|$개 정점을 모두 방문하고 $|V| - 1$개 간선을 쓰므로, 변환된 인스턴스에서 총 가중치가 $|V| - 1 = K$이다. 따라서 HAM-PATH의 Yes 인스턴스는 LONGEST-PATH의 Yes 인스턴스로 바뀐다.

**역방향.** 변환된 그래프에서 가중치가 $|V| - 1$ 이상인 단순 $s \to t$ 경로는 간선이 $|V| - 1$개 이상이다. 단순 경로의 간선은 최대 $|V| - 1$개이므로 이 경로는 *정확히* $|V| - 1$개 간선을 갖고 *모든* $|V|$개 정점을 방문한다. 즉 Hamilton $s \to t$ 경로이다.

변환은 $O(|E|)$이다. 따라서 LONGEST-PATH는 NP-Hard이고, Step 1과 합치면 **LONGEST-PATH는 NP-Complete**이다. $\blacksquare$

### 2.9 스케치: 3-SAT $\leq_P$ CLIQUE

**3-SAT.** 각 절이 정확히 3개의 리터럴을 갖는 CNF 식이 주어질 때, 만족하는 할당이 있는가?

**CLIQUE.** 그래프 $G$가 크기 $k$인 완전 부분 그래프를 가지는가?

**환원.** 절이 $m$개인 3-SAT 인스턴스가 주어지면 그래프 $G_\phi$를 다음과 같이 구성한다.

- 각 절의 각 리터럴마다 정점을 만든다(절당 3개, 총 $3m$개 정점).
- 두 정점 사이에 간선을 추가하되, 다음 경우에는 추가하지 않는다.
  - 두 정점이 **같은 절**에 있는 경우.
  - 두 정점이 $x_i$와 $\overline{x_i}$처럼 **모순적**인 경우.
- $k = m$(절의 수)으로 둔다.

![그림 9. 3-SAT에서 CLIQUE로의 환원 그래프 구성](../../images/Week13_ch34_p41.png)

*그림 9. 3-SAT에서 CLIQUE로의 환원 그래프 구성*

**왜 동작하는가.** $G_\phi$의 크기 $m$인 clique은 같은 절의 정점끼리 연결되지 않으므로 절마다 리터럴을 하나씩 고르고, 모순 쌍이 연결되지 않으므로 모순 없이 고른다. clique에 속한 리터럴을 모두 True로 두면 모든 절이 만족된다. 역으로 만족 할당에서 절마다 참인 리터럴을 하나씩 고르면 그 선택은 clique을 이룬다.

구성은 다항 시간이다. 따라서 $\text{3-SAT} \leq_P \text{CLIQUE}$이고 CLIQUE은 NP-Hard이다.

### 2.11 직관에 반하는 경계

비슷해 *보이는* 문제들이 크게 다른 복잡도를 갖기도 한다.

| 문제                                                  | 복잡도        | 알고리즘                    |
|-------------------------------------------------------|---------------|----------------------------|
| **Shortest Path**                                     | P             | Dijkstra $O(V^2)$           |
| **Longest Path**                                      | NP-Complete   | 알려진 다항 시간 알고리즘 없음 |
| **Euler Circuit** (모든 **간선** 한 번씩)              | P             | Hierholzer $O(E)$           |
| **Hamiltonian Cycle** (모든 **정점** 한 번씩)          | NP-Complete   | 알려진 다항 시간 알고리즘 없음 |
| **2-SAT**                                             | P             | 함의 그래프 $O(n+m)$         |
| **3-SAT**                                             | NP-Complete   | 알려진 다항 시간 알고리즘 없음 |
| **2-Coloring**                                        | P             | BFS / DFS $O(V+E)$          |
| **3-Coloring**                                        | NP-Complete   | 알려진 다항 시간 알고리즘 없음 |

*표 4. 비슷해 보이지만 복잡도가 다른 문제 쌍*

> **핵심:** P와 NP-Complete 사이의 경계는 놀라울 만큼 얇다. 간선 대신 정점, 절당 리터럴 2개 대신 3개, 최단 대신 최장처럼 제약 하나만 달라져도 다항 시간 문제가 효율적 알고리즘이 알려지지 않은 문제로 바뀐다. 여기에는 깊은 의미가 있으며, 무엇이 문제를 어렵게 만드는가는 지금도 활발한 연구 주제이다.

### 2.12 "NP-Complete"가 실전에서 의미하는 것

문제가 NP-Complete임이 증명되면 다음과 같이 대응한다.

1. **정확한 다항 시간 알고리즘의 탐색을 중단한다.** 50년 넘게 어떤 NP-Complete 문제에 대해서도 그런 알고리즘이 발견되지 않았으며, 새로 찾아낼 가능성도 매우 낮다.
2. **휴리스틱을 사용한다.** 휴리스틱은 품질 보장 없이 실용적인 인스턴스에서 좋은(때로는 최적인) 해를 찾는 알고리즘이다.
3. **근사 알고리즘을 사용한다.** 근사 알고리즘은 해 품질에 대해 증명 가능한 한계를 가진 다항 시간 알고리즘이며, 3절부터 다룬다.
4. **특수 경우 해결법을 사용한다.** 많은 NP-Complete 문제가 트리, 평면 그래프, treewidth가 제한된 그래프 같은 제한된 입력에서는 다항 시간에 풀린다.

> **참고:** **Leonid Levin의 말.** NP-완비성을 Cook과 독립적으로 발견한 Leonid Levin은 "때로는 어떤 것이 불가능함을 아는 것이 유용하다"라고 말했다.

## 3. 근사 알고리즘의 기초

### 3.1 왜 근사인가?

NP-Complete 문제는 라우팅, 스케줄링, 패킹, 커버링, 클러스터링 등 *어디에나* 나타난다. 이런 문제의 최적해를 다항 시간에 찾는 방법은 알려져 있지 않으므로, 이 문제들을 다루려면 다음 세 가지 중 **하나를 포기**해야 한다.

1. **다항 시간**에 해를 찾는 것.
2. **모든 입력**에 대해 해를 찾는 것.
3. **최적** 해를 찾는 것.

**근사 알고리즘은 (3)을 포기**하고, 다항 시간에 거의 최적인 해를 **증명 가능한 품질 보장**과 함께 찾는다. 휴리스틱도 (3)을 포기하지만 증명 가능한 보장이 없다. 무작위 알고리즘은 때때로 (2)를 확률적으로 포기하고, 지수 시간 정확 알고리즘은 (1)을 포기한다.

### 3.2 근사 비율

근사 알고리즘에는 **근사 비율(approximation ratio)** 이 따른다.

$$
\rho = \frac{\text{근사해의 값}}{\text{최적해의 값}}
$$

최대화 문제는 비율을 뒤집어 항상 $\rho \geq 1$이 되도록 진술한다.

- $\rho$가 $1.0$에 가까울수록 해의 품질이 높다.
- $\rho = 2.0$은 최적의 2배 이내인 해를 뜻하며, 이를 **2-근사(2-approximation)** 라 한다.
- **함정:** $\rho$를 계산하려면 최적값이 필요한데, 최적값은 다항 시간에 구할 방법이 알려져 있지 않은 값이다. 따라서 교묘한 우회가 필요하다.

### 3.3 간접 최적해 기법

닭과 달걀 문제를 우회하는 방법은 **쉽게 계산할 수 있는 최적해의 경계**를 사용해 그 경계에 대해 근사 비율을 증명하는 것이다.

**최소화 문제:**
- 계산 가능한 값 $L$로 $\text{OPT} \geq L$(OPT의 하한)을 찾는다.
- $\text{APX} \leq c \cdot L$임을 보인다.
- 그러면 $\text{APX} \leq c \cdot \text{OPT}$이고 근사 비율은 $c$이다.

**최대화 문제:**
- 계산 가능한 값 $U$로 $\text{OPT} \leq U$(OPT의 상한)를 찾는다.
- $\text{APX} \geq U / c$임을 보인다.
- 그러면 $\text{APX} \geq \text{OPT} / c$이다.

> **참고:** **왜 동작하는가.** 이 기법은 OPT 자체를 *우회*하며 OPT를 직접 계산하지 않는다. 계산 가능한 경계와 알고리즘의 출력 사이에 OPT를 끼워 넣을 뿐이다. 4~8절의 모든 2-근사 증명이 이 틀을 따른다.

## 4. TSP의 MST 기반 2-근사

### 4.1 문제와 거리 공간(metric) 가정

**Traveling Salesman Problem (TSP).** 외판원이 한 도시에서 출발해 다른 모든 도시를 정확히 한 번씩 방문하고 출발지로 돌아온다. **목표:** 총 이동 거리를 최소화한다.

**Metric TSP**는 다음을 가정한다.

- **대칭성:** $d(A, B) = d(B, A)$.
- **삼각 부등식:** $d(A, B) \leq d(A, C) + d(C, B)$.

두 가정은 유클리드 거리와 많은 실세계 비용 모델에서 성립한다. 삼각 부등식이 없으면 $P = NP$가 아닌 한 TSP를 어떤 상수 인자로도 근사할 수 없다. 즉 metric 가정이 2-근사를 가능하게 한다.

### 4.2 알고리즘

MST(11주차)를 구한 뒤 그 트리를 순회한다.

**Approx_MST_TSP**(입력: $n$개 도시와 쌍별 거리)

```text
1. Kruskal 또는 Prim으로 입력 그래프의 MST 계산.
2. 임의의 도시에서 시작해 MST를 DFS 순회,
   정점 방문 순서 기록.
   (각 트리 간선은 두 번 사용: 진행 한 번, 되돌아옴 한 번.)
3. 방문 순서에서 중복 도시 제거, 각 도시의 첫 등장만 유지;
   끝에 시작 도시 추가.
4. 결과 투어 반환.
```

Step 3이 **shortcut(지름길)** 단계이다. DFS가 이미 방문한 정점을 다시 지날 때 다음 미방문 정점으로 직접 건너뛴다. 삼각 부등식은 이 지름길이 대체되는 경로보다 길지 않음을 보장한다.

### 4.3 풀이 예시

8개 도시 $A, B, C, D, E, F, G, H$와 그 MST를 생각한다.

**Step 1: MST 구축.** Kruskal 또는 Prim 알고리즘을 적용해 8개 정점을 연결하는 트리 간선들을 얻는다.

**Step 2: DFS 순회** ($A$에서 시작):

$$
A \to G \to E \to G \to D \to H \to C \to H \to D \to F \to B \to F \to D \to G \to A
$$

총 길이는 $2M$이다. 여기서 $M$은 MST의 총 가중치이며, $n - 1$개의 트리 간선이 각각 두 번 사용되기 때문이다.

**Step 3: 중복 제거** (shortcut):

$$
A \to G \to E \to \cancel{G} \to D \to H \to C \to \cancel{H} \to \cancel{D} \to F \to B \to \cancel{F} \to \cancel{D} \to \cancel{G} \to A
$$

**최종 투어:** $A \to G \to E \to D \to H \to C \to F \to B \to A$.

삼각 부등식에 의해 결과 투어의 길이는 $2M$ 이하이다.

### 4.4 근사 비율 증명

**주장:** Approx_MST_TSP의 근사 비율은 $2.0$보다 작다.

$M$은 MST의 총 가중치, $\text{OPT}$는 최적 TSP 투어의 길이, $\text{APX}$는 근사 투어의 길이이다.

**Step 1.** $\text{OPT} > M$.

*이유:* 최적 투어는 모든 정점을 방문하고 시작점으로 돌아온다. 투어에서 간선 하나를 제거하면 신장 트리가 남는다. 이 트리는 모든 정점을 포함하고 연결되어 있으며 간선은 $|V| - 1$개이다. $M$은 *최소* 신장 트리의 가중치이므로 $M \leq (\text{투어 - 한 간선})$이다. 제거한 간선의 가중치가 **양수**라면 $(\text{투어 - 한 간선}) < \text{OPT}$이고, 따라서 $M < \text{OPT}$이다. 모든 간선 가중치가 양수인 통상적인 경우에는 비율이 엄격히 $2$보다 작다. 가중치가 0인 간선이 허용되면 $M \leq \text{OPT}$만 얻으므로 한계는 $\leq 2$가 된다.

**Step 2.** $\text{APX} \leq 2M$.

*이유:* DFS 순회의 길이는 정확히 $2M$이다. Step 3의 shortcut은 순회의 부분 경로 $x \to y \to z$를 직접 간선 $x \to z$로 바꾼다. 삼각 부등식에 따르면 $d(x, z) \leq d(x, y) + d(y, z)$이므로 shortcut은 경로를 더 길게 만들지 않는다.

**합치면** $\text{APX} \leq 2M < 2 \cdot \text{OPT}$이므로 다음이 성립한다.

$$
\frac{\text{APX}}{\text{OPT}} < 2.0. \qquad \blacksquare
$$

### 4.5 복잡도

| 단계 | 연산                       | 복잡도        |
|------|----------------------------|---------------|
| 1    | MST 구축 (Kruskal)         | $O(m \log m)$ |
| 1    | MST 구축 (Prim)            | $O(n^2)$      |
| 2    | DFS 순회                   | $O(n)$        |
| 3    | 중복 제거                  | $O(n)$        |

*표 5. Approx_MST_TSP의 단계별 복잡도*

**전체:** MST 구축이 지배하므로 Prim 알고리즘으로 $O(n^2)$, Kruskal 알고리즘으로 $O(m \log m)$이다.

## 5. Vertex Cover의 Maximal-Matching 2-근사

### 5.1 문제

그래프 $G = (V, E)$의 **vertex cover**는 모든 간선의 끝점 중 적어도 하나가 속하는 부분집합 $S \subseteq V$이다. **목표:** 크기가 최소인 vertex cover를 찾는다.

**실세계 비유:** 모든 복도(간선)가 감시되도록 교차로에 CCTV 카메라를 최소 개수로 설치하는 문제와 같다.

![그림 12. Vertex cover 예시](../../images/Week13_ch34_p43.png)

*그림 12. Vertex cover 예시*

### 5.2 알고리즘

**핵심 통찰:** 비싼 set-cover 식 환원 대신 **maximal matching**을 만들고 그 모든 끝점을 취한다.

- **Matching:** 끝점을 공유하지 않는 간선 집합이다.
- **Maximal matching:** 더 이상 간선을 추가할 수 없는 matching(그리디의 정지점)이다. 가장 큰 matching인 **maximum** matching과는 다르다.
- Maximal matching은 *그리디로* 다항 시간에 찾을 수 있다.

**Approx_Matching_VC**(입력: 그래프 $G = (V, E)$)

```text
1. G의 maximal matching M 찾기:
   - M ← ∅
   - 각 간선 (u, v) ∈ E 에 대해:
       만약 u 도 v 도 M의 어떤 간선의 끝점이 아니면,
       (u, v) 를 M에 추가.
2. M의 모든 간선의 끝점 집합 반환.
```

### 5.3 풀이 예시와 증명

```text
9 정점 그래프:
   1 --- 2 --- 3
   |   / |   / |
   4 --- 5 --- 6
   |   / |   / |
   7 --- 8 --- 9
```

*그림 13. 정점 9개와 간선 16개로 이루어진 예시 그래프*

간선을 $(1,2), (2,3), (4,5), (5,6), (7,8), (8,9), (1,4), (4,7), (2,5), (5,8), (3,6), (6,9), (2,4), (3,5), (5,7), (6,8)$ 순서로 검사하면, 그리디 maximal matching은 $M = \{(1,2), (4,5), (7,8), (3,6)\}$의 간선 4개를 고른다. 알고리즘은 끝점 $2 \cdot 4 = 8$개, 즉 $\{1, 2, 3, 4, 5, 6, 7, 8\}$을 반환한다. 정점을 clique $\{1, 2, 4\}$, $\{3, 5, 6\}$, $\{7, 8\}$, $\{9\}$로 나누면 independent set은 각 clique에서 정점을 최대 하나만 가지므로 크기가 4 이하이고, 따라서 vertex cover는 정점이 $9 - 4 = 5$개 이상이다. $\{2, 4, 5, 6, 8\}$이 크기 5인 vertex cover이므로 최적값은 5이고, 비율은 $8 / 5 = 1.6$으로 보장된 $2.0$ 안에 들어온다.

정점이 9개인 그래프의 matching은 간선을 최대 4개까지만 가질 수 있다. 정점이 더 많은 그래프에서 그리디 maximal matching이 간선 6개를 골랐다면 알고리즘은 끝점 $2 \cdot 6 = 12$개를 반환하며, 그때 최적 vertex cover가 7이라면 비율은 $12 / 7 \approx 1.71$이다.

**근사 비율 증명.**

**주장:** Approx_Matching_VC의 근사 비율은 $2.0$ 이하이다.

$|M|$은 maximal matching의 간선 수, $\text{OPT}$는 최적 vertex cover의 크기이다.

**Step 1.** $\text{OPT} \geq |M|$.

*이유:* 모든 vertex cover는 각 matching 간선의 끝점을 적어도 하나 포함해야 한다. 그렇지 않으면 그 간선이 커버되지 않는다. Matching 간선들은 끝점을 공유하지 않으므로 서로 다른 matching 간선에는 *서로 다른* 정점이 필요하며, 따라서 정점이 $|M|$개 이상 필요하다.

**Step 2.** $\text{APX} = 2|M|$.

*이유:* 알고리즘은 모든 matching 간선의 두 끝점을 반환한다. Matching 간선은 끝점을 공유하지 않으므로 반환되는 정점은 모두 서로 다르며 정확히 $2|M|$개이다.

**합치면:**
$$
\frac{\text{APX}}{\text{OPT}} = \frac{2|M|}{\text{OPT}} \leq \frac{2|M|}{|M|} = 2.0. \qquad \blacksquare
$$

**복잡도.** 각 간선마다 끝점이 이미 쓰였는지 $M$을 훑어 확인하면 간선당 $O(n)$이 걸리므로, 간선 $m$개에 대해 총 **$O(nm)$** 시간이 걸린다. 정점마다 사용 여부를 표시하는 배열을 쓰면 간선당 $O(1)$이 되어 $O(n + m)$으로 줄어든다.

## 6. Bin Packing의 네 가지 그리디 휴리스틱

### 6.1 문제

크기가 $s_1, s_2, \dots, s_n$(각각 $C$ 이하)인 $n$개 아이템과 용량 $C$인 빈이 주어졌을 때, 모든 아이템을 **최소 개수의 빈**에 패킹한다.

응용 분야로는 메모리 할당, 컨테이너 적재, 디스크 파티셔닝, 가상 머신 패킹이 있다.

### 6.2 First Fit / Next Fit / Best Fit / Worst Fit

| 방법 | 전략 |
|------|------|
| **First Fit (FF)** | 각 아이템을 공간이 충분한 **첫 빈**에 놓는다. |
| **Next Fit (NF)**  | **가장 최근에 사용한 빈**만 확인하고, 들어가지 않으면 새 빈을 연다. |
| **Best Fit (BF)**  | 들어가는 빈 중 놓은 뒤 **남는 공간이 최소**가 되는 빈에 놓는다. |
| **Worst Fit (WF)** | 들어가는 빈 중 놓은 뒤 **남는 공간이 최대**가 되는 빈에 놓는다. |

*표 6. Bin Packing 네 가지 휴리스틱의 배치 전략*

모든 방법에서, 들어갈 기존 빈이 없으면 새 빈을 연다.

```text
Approx_BinPacking(아이템 s_1, …, s_n, 용량 C):
    B = 0
    for i = 1 to n:
        if 선택된 전략대로 충분한 빈이 존재:
            거기에 아이템 i 놓음
        else:
            새 빈 오픈, 아이템 i 놓음, B = B + 1
    return B
```

### 6.3 풀이 예시

$C = 10$이고 아이템은 $[7, 5, 6, 4, 2, 3, 7, 5]$이다.

| 방법         | 빈 내용                                | 빈 사용 |
|--------------|----------------------------------------|---------|
| First Fit    | {7,2}, {5,4}, {6,3}, {7}, {5}          | 5       |
| Next Fit     | {7}, {5}, {6,4}, {2,3}, {7}, {5}       | 6       |
| Best Fit     | {7,2}, {5,3}, {6,4}, {7}, {5}          | 5       |
| Worst Fit    | {7,3}, {5,4}, {6,2}, {7}, {5}          | 5       |
| **Optimal**  | {7,3}, {5,5}, {6,4}, {7,2}             | **4**   |

*표 7. C = 10일 때 휴리스틱별 빈 배치 결과*

### 6.4 근사 비율 증명

**주장:** First Fit, Best Fit, Worst Fit은 모두 $\rho \leq 2.0$을 달성한다.

**핵심 관찰.** 종료 시점에 절반 이하로 찬 빈은 최대 **하나**이다. *이유:* 두 빈이 각각 $C/2$ 이하로 차 있다면, 나중에 연 빈의 첫 아이템은 먼저 연 빈에 들어갈 수 있었다. 이는 들어갈 기존 빈이 있으면 새 빈을 열지 않는 FF/BF/WF의 그리디 규칙에 모순이다.

**증명.** $\text{OPT}'$은 알고리즘이 사용한 빈 수, $\text{OPT}$는 최적 빈 수이다. 적어도 $\text{OPT}' - 1$개 빈이 절반 *초과*로 차 있으므로 다음이 성립한다.

$$
\sum s_i > (\text{OPT}' - 1) \cdot \frac{C}{2}
$$

최적해도 부피만 따져 적어도 $\sum s_i / C$개의 빈을 써야 하므로 $\text{OPT} \geq \sum s_i / C$이다. 합치면 다음과 같다.

$$
\text{OPT} \geq \frac{\sum s_i}{C} > \frac{\text{OPT}' - 1}{2}
\implies 2 \cdot \text{OPT} > \text{OPT}' - 1
\implies 2 \cdot \text{OPT} \geq \text{OPT}'.
\qquad \blacksquare
$$

**주장:** Next Fit도 약간 다른 논증으로 $\rho \leq 2.0$을 달성한다.

**핵심 관찰.** Next Fit에서 *연속된* 두 빈의 내용 합은 $C$보다 크다. *이유:* 두 번째 빈의 첫 아이템이 첫 번째 빈에 들어갔다면 Next Fit은 두 번째 빈을 열지 않았을 것이다.

**증명.** 연속한 빈을 (bin 1, bin 2), (bin 3, bin 4), ...처럼 쌍으로 묶는다. 완전한 쌍은 $\lfloor \text{OPT}' / 2 \rfloor$개이고 각 쌍의 내용 합은 $C$보다 크다.

$$
\sum s_i > \left\lfloor \frac{\text{OPT}'}{2} \right\rfloor \cdot C
\implies \text{OPT} \geq \frac{\sum s_i}{C} > \left\lfloor \frac{\text{OPT}'}{2} \right\rfloor
\implies \text{OPT} \geq \left\lfloor \frac{\text{OPT}'}{2} \right\rfloor + 1 > \frac{\text{OPT}'}{2}
\implies 2 \cdot \text{OPT} > \text{OPT}'.
\qquad \blacksquare
$$

**복잡도:**

| 방법 | 아이템당 작업       | 총합     |
|------|---------------------|----------|
| First Fit  | 모든 빈 스캔, $O(n)$ | $O(n^2)$ |
| Best Fit   | 모든 빈 스캔, $O(n)$ | $O(n^2)$ |
| Worst Fit  | 모든 빈 스캔, $O(n)$ | $O(n^2)$ |
| Next Fit   | 한 빈 확인, $O(1)$   | $O(n)$   |

*표 8. Bin Packing 휴리스틱별 시간 복잡도*

> **참고:** **실전에서의 개선.** 아이템을 크기의 *내림차순*으로 먼저 정렬하면(First Fit Decreasing, Best Fit Decreasing) 점근적으로 $11/9$ 근처의 더 좋은 비율을 얻는다. 이 분석은 이 정리본의 범위를 넘는다.

## 7. Job Scheduling의 가장 빨리 끝나는 기계 2-근사

### 7.1 문제

- 작업이 $n$개 있고, 처리 시간은 $t_1, t_2, \dots, t_n$이다.
- 동일한 기계가 $m$개 있다($M_1, \dots, M_m$).
- 각 작업은 정확히 한 기계에서 중단 없이 실행되고, 각 기계는 한 번에 한 작업만 처리한다.

**목표:** 작업을 기계에 할당해 **makespan**(마지막 작업의 완료 시간)을 최소화한다.

### 7.2 알고리즘과 풀이 예시

**알고리즘.** 새 작업이 도착하면 가장 **빨리** 비는 기계에 할당한다.

```text
Approx_JobScheduling(시간 t_1, …, t_n, m 기계):
    for j = 1 to m:
        L[j] = 0                       // 기계 j 의 현재 완료 시간
    for i = 1 to n:
        min = 1
        for j = 2 to m:
            if L[j] < L[min]:
                min = j
        작업 i 를 기계 M_min 에 할당
        L[min] = L[min] + t_i
    return max(L[1], …, L[m])
```

**풀이 예시.** 작업은 $t = [5, 2, 4, 3, 4, 7, 9, 2, 4, 1]$이고 기계는 $m = 4$개이다.

| 작업 | $t_i$ | 할당 | 이후 load        |
|------|-------|------|-------------------|
| 1    | 5     | M1   | [5, 0, 0, 0]      |
| 2    | 2     | M2   | [5, 2, 0, 0]      |
| 3    | 4     | M3   | [5, 2, 4, 0]      |
| 4    | 3     | M4   | [5, 2, 4, 3]      |
| 5    | 4     | M2   | [5, 6, 4, 3]      |
| 6    | 7     | M4   | [5, 6, 4, 10]     |
| 7    | 9     | M3   | [5, 6, 13, 10]    |
| 8    | 2     | M1   | [7, 6, 13, 10]    |
| 9    | 4     | M2   | [7, 10, 13, 10]   |
| 10   | 1     | M1   | [8, 10, 13, 10]   |

*표 9. Approx_JobScheduling의 작업별 할당 과정*

**Makespan (APX) = 13.**

### 7.3 근사 비율 증명

**주장:** Approx_JobScheduling의 근사 비율은 $2.0$ 이하이다.

Makespan을 결정하는 작업, 즉 가장 늦게 끝나는 작업을 작업 $i$라 하고, 작업 $i$가 시각 $T$에 시작한다고 하자. 그러면 $\text{APX} = T + t_i$이다.

**OPT의 두 하한:**

1. **부피 한계:** $\text{OPT} \geq \frac{\sum_j t_j}{m}$. 부하가 완벽하게 균형을 이루더라도 어떤 기계는 적어도 평균만큼 실행되어야 한다.
2. **작업당 한계:** $\text{OPT} \geq t_i$. 어떤 일정이든 작업 $i$를 어딘가에서 처리해야 하며, 그 처리에 $t_i$가 걸린다.

**증명.** 작업 $i$는 배치 시점에 가장 빨리 끝나는 기계에 놓였으므로, $T$는 $i$를 놓기 직전 모든 기계 완료 시간의 평균 이하이다. $i$가 아직 할당되지 않았으므로 그 평균은 다시 $i$를 제외한 모든 작업 시간의 합을 $m$으로 나눈 값 이하이다.

$$
T \leq \frac{\sum_{j \neq i} t_j}{m} \leq \frac{\sum_j t_j}{m} \leq \text{OPT}.
$$

$t_i \leq \text{OPT}$와 합치면 다음을 얻는다.

$$
\text{APX} = T + t_i \leq \text{OPT} + \text{OPT} = 2 \cdot \text{OPT}. \qquad \blacksquare
$$

**복잡도:** $n$개 작업 각각에 대해 $m$개 기계 부하의 최솟값을 찾으므로 총 **$O(nm)$** 시간이 걸린다.

> **참고:** **실전에서의 개선.** **Longest Processing Time First (LPT)** 변형은 같은 그리디 할당 전에 작업을 $t_i$의 내림차순으로 정렬한다. 이 방법은 $4/3$ 근사 비율을 달성하고 경험적으로도 훨씬 더 잘 동작한다.

## 8. k-Clustering의 Farthest-First 2-근사

### 8.1 문제

**k-Clustering Problem.** 2차원 평면(또는 임의의 metric 공간)의 점 $n$개와 정수 $k$가 주어졌을 때, 점들을 **$k$개 그룹**으로 분할하고 각 그룹에 **중심** 점을 지정한다. **목표:** **최대 클러스터 지름**(가장 큰 클러스터의 지름)을 최소화한다.

응용 분야로는 추천 시스템, 데이터 마이닝, VLSI 설계, 병렬 처리, 웹 검색, 패턴 인식, 유전자 분석, 소셜 네트워크 분석이 있다.

### 8.2 알고리즘과 풀이 예시

**Farthest-First Traversal (그리디).** 중심을 하나씩 고르되, 매번 지금까지 고른 모든 중심으로부터 **가장 먼** 점을 선택한다.

```text
Approx_k_Clusters(점 x_0, …, x_{n-1}, k > 1):
    C[1] = x_r                            // 무작위 첫 중심
    for j = 2 to k:
        각 비-중심 점 x_i 에 대해:
            D[i] = x_i 에서 임의의 기존 중심까지의 최소 거리
        C[j] = 가장 큰 D[i] 를 갖는 점 x_i
    각 비-중심 점을 가장 가까운 중심에 할당
    return 중심 C 와 클러스터 할당
```

**직관:** 중심을 멀리 펼치면 모든 클러스터가 작은 영역만 덮게 된다.

**풀이 예시 ($k = 4$).**

- **Step 1:** 임의의 점을 $C_1$로 선택한다.
- **Step 2:** 모든 비중심 점에 대해 $D[i]$를 계산하고, $C_1$에서 가장 먼 점을 $C_2$로 선택한다.
- **Step 3:** 남은 각 점에 대해 $D[i] = \min(d(x_i, C_1), d(x_i, C_2))$를 계산하고, $D[i]$가 가장 큰 점을 $C_3$으로 선택한다. 예를 들어 $D[3] = 20$이 가장 크면 $C_3 = x_3$이다.
- **Step 4:** $D[i] = \min(d(x_i, C_1), d(x_i, C_2), d(x_i, C_3))$를 다시 계산하고, 가장 큰 점을 $C_4$로 선택한다.
- **Step 5:** 각 비중심 점을 가장 가까운 중심에 할당한다.

### 8.3 근사 비율 증명

**주장:** Approx_k_Clusters의 근사 비율은 $2.0$ 이하이다.

**설정.** $k$개 중심을 고른 뒤 같은 farthest-first 규칙으로 **가상의 $(k+1)$번째 중심** $C_{k+1}$을 하나 더 고른다고 하자. $d$는 $C_{k+1}$에서 가장 가까운 기존 중심까지의 거리이다.

**Step 1: $\text{OPT} \geq d$.** 이제 $k + 1$개 점을 $k$개의 최적 그룹으로 나누어야 한다. **비둘기집 원리**에 의해 적어도 한 최적 그룹이 이 $k+1$개 중심 중 둘 이상을 포함한다. *그* 그룹의 지름은 그 안의 두 중심 사이 거리 이상이다. Farthest-first 구성에서는 $k+1$개 중심 사이의 최소 쌍 거리가 $d$이므로 그 거리는 $d$ 이상이다. 따라서 $\text{OPT} \geq d$이다.

**Step 2: $\text{APX} \leq 2d$.** $C_{k+1}$은 기존 중심들로부터 가장 먼 점이므로, **모든** 다른 점은 가장 가까운 중심으로부터 거리 $d$ 이내에 있다. 따라서 각 클러스터의 반지름은 $d$ 이하이고, 삼각 부등식에 의해 지름은 $2d$ 이하이다.

**합치면:**
$$
2 \cdot \text{OPT} \geq 2d \geq \text{APX}
\implies \frac{\text{APX}}{\text{OPT}} \leq 2.0. \qquad \blacksquare
$$

**복잡도.** 내부 루프는 $n$개 점과 $k$개 중심에 대해 $D[i]$를 계산하므로 $O(kn)$이다. 외부 루프는 $k - 1$회 실행되므로 $(k-1) \cdot O(kn) = O(k^2 n)$이다. 최종 할당은 $O(kn)$이다. 따라서 **총 시간은 $O(k^2 n)$이다.**

### 8.4 실용적 고려 사항

- **무작위 첫 중심:** 결과가 실행마다 다르므로 여러 번 실행한 뒤 가장 좋은 결과를 택한다.
- **이상치 민감성:** 노이즈 점이 중심 선택을 왜곡하므로 이상치를 제거하는 전처리를 한다.
- **유산:** 이 알고리즘은 **k-center 문제**와 밀접하며 **Gonzalez 알고리즘**(1985)이라고도 불린다. 현대 k-means에 쓰이는 **k-means++** 초기화에 영감을 주었다.

## 9. 근사 알고리즘의 요약 표

| 문제                  | 간접 최적해 경계                                       | 비율       | 시간            |
|-----------------------|--------------------------------------------------------|------------|-----------------|
| **TSP** (Metric)      | $M$ = MST 가중치 ($\text{OPT} > M$)                    | $< 2.0$    | $O(n^2)$ 또는 $O(m \log m)$ |
| **Vertex Cover**      | $\vert M \vert$ = maximal matching 크기 ($\text{OPT} \geq \vert M \vert$)  | $\leq 2.0$ | $O(nm)$         |
| **Bin Packing (FF/BF/WF)** | $\sum s_i / C$ ($\text{OPT} \geq \sum s_i / C$)   | $\leq 2.0$ | $O(n^2)$        |
| **Bin Packing (NF)**  | $\sum s_i / C$                                         | $\leq 2.0$ | $O(n)$          |
| **Job Scheduling**    | $\sum t_i / m$과 $\max t_i$                            | $\leq 2.0$ | $O(nm)$         |
| **k-Clustering**      | 가상 $(k+1)$번째 중심 거리 $d$                          | $\leq 2.0$ | $O(k^2 n)$      |

*표 10. 다섯 근사 알고리즘의 간접 최적해 경계, 근사 비율, 시간 복잡도*

다섯 문제 모두 **2-근사**이며, 최적의 최대 2배인 해를 낸다. 근사 알고리즘은 14주차에서 이어서 다룬다.

| NP-Complete 문제의 대처 | 문제가 NP-Complete임이 증명되면 휴리스틱, 근사, 특수 경우 알고리즘으로 전환한다. |
| 근사 비율 | $\text{APX} / \text{OPT}$로 정의되는 품질의 표준 척도이며, OPT의 간접 경계로 증명한다. |
| 간접 최적해 기법 | OPT를 계산 가능한 경계와 알고리즘 출력 사이에 끼워 넣는 보편적인 증명 방식이며, 4~8절의 모든 2-근사 증명이 이를 따른다. |
| 다섯 가지 2-근사 | TSP, Vertex Cover, Bin Packing, Job Scheduling, Clustering의 정석적 근사 알고리즘은 모두 간단한 그리디 전략과 깔끔한 증명으로 인자 2의 보장을 얻는다. |
| 전체 흐름 | 정확히 풀 수 없다면 어려움을 증명하고, 어렵다면 근사한 뒤 그 근사의 성능을 증명한다. |

## 점검 문제

1. **P vs NP 직관:** 풀기(*solve*)와 검증(*verify*)이라는 단어를 써서 P와 NP의 차이를 일상 언어로 설명하라. P의 모든 문제가 자동으로 NP에 속하는 이유는 무엇인가?

   <details>
   <summary>정답</summary>

   **P**는 다항 시간에 Yes/No 답을 처음부터 정확히 계산할 수 있는 결정 문제의 클래스이다. 즉, 빨리 **풀** 수 있다. **NP**는 후보 Yes certificate(제안된 해)가 주어지면 그 유효성을 다항 시간에 **검증**할 수 있는 클래스이다. P의 모든 문제는 NP에 속한다. 검증기가 certificate를 무시하고 문제를 다시 풀면 되기 때문이다. 반대 방향, 즉 빠른 검증이 빠른 풀이를 함의하는지가 $P = NP$ 질문이다.

   </details>

2. **결정 vs 최적화:** TSP에는 두 형태가 있다. 각각을 분명히 진술하고, NP-완비성은 결정 버전으로 증명되지만 어려움이 최적화 버전으로 여전히 이전되는 이유를 설명하라.

   <details>
   <summary>정답</summary>

   **결정 버전**은 가중 완전 그래프 $G$와 한계 $K$가 주어졌을 때 $G$가 총 가중치 $\leq K$인 투어를 갖는지 묻는다. 답은 Yes 또는 No이다. **최적화 버전**은 $G$의 최소 투어 가중치를 묻는다. NP-완비성은 환원 기구 $A \leq_P B$가 Yes/No 보존을 요구하므로 결정 문제로 정의된다. **어려움이 이전되는** 이유는 최적화 문제를 풀면 최솟값과 $K$를 비교해 결정 문제도 풀 수 있기 때문이다. 따라서 최적화 버전은 결정 버전만큼 어렵다. 결정 버전이 NP-Complete라면 ($P \neq NP$를 가정할 때) 최적화 버전에도 다항 시간 알고리즘이 없다.

   </details>

3. **환원의 방향:** 한 학생이 "Hamiltonian Cycle이 TSP로 환원되니 TSP가 Hamiltonian Cycle보다 쉽겠네"라고 말한다. 이 말은 옳은가 틀린가, 그리고 그 이유는 무엇인가?

   <details>
   <summary>정답</summary>

   **틀렸다.** $A \leq_P B$는 $A$를 $B$로 변환해 $B$의 알고리즘으로 풀 수 있다는 뜻이다. 따라서 $B$는 적어도 $A$만큼 어렵다. 환원 방향은 $A$가 $B$보다 더 어렵지 않다는 뜻이기도 하다. Hamiltonian Cycle은 NP-Complete이고 TSP로 환원되므로 **TSP도 NP-Hard**이다. TSP는 적어도 Hamiltonian Cycle만큼 어렵다. 학생은 이 관계를 거꾸로 이해했다.

   </details>

4. **LONGEST-PATH 증명:** LONGEST-PATH NP-완비성 증명의 두 핵심 방향을 재현하라. 특히 역방향에 가중치 1 트릭이 필요한 이유는 무엇인가?

   <details>
   <summary>정답</summary>

   **정방향 (HAM-PATH-2-POINTS → LONGEST-PATH):** $G$에 $s$에서 $t$로 가는 Hamilton 경로가 있다고 하자. 변환된 그래프에서는 모든 간선의 가중치가 1이고 $K = |V| - 1$이다. 같은 경로는 간선이 $|V| - 1$개이므로 가중치 합도 $|V| - 1 = K$이다. 따라서 LONGEST-PATH의 Yes 인스턴스이다. **역방향 (LONGEST-PATH → HAM-PATH-2-POINTS):** 변환된 그래프의 단순 $s \to t$ 경로가 가중치 $\geq |V| - 1$이면 간선도 $|V| - 1$개 이상 포함한다. 단순 경로는 각 정점을 최대 한 번 방문하므로 간선을 최대 $|V| - 1$개만 가질 수 있다. 따라서 간선이 정확히 $|V| - 1$개이고 모든 정점을 방문하므로 Hamilton 경로이다. **가중치 1 트릭**은 경로의 가중치와 간선 수를 같게 만들어 $K = |V| - 1$이 모든 정점 방문을 강제한다. 가중치가 서로 다르면 무거운 간선 몇 개로 이루어진 짧은 경로도 기준 가중치를 넘을 수 있어 역방향이 성립하지 않는다.

   </details>

5. **유사 다항 역설:** 0-1 Knapsack은 $O(nC)$ DP 해법이 있는데도 NP-Complete이다. 이 명백한 모순을 해소하라.

   <details>
   <summary>정답</summary>

   NP-완비성 이론에서 다항 시간이란 입력의 **수치 값**이 아니라 **비트 길이**에 대한 다항 시간을 뜻한다. 용량 $C$는 입력에서 $\log_2 C$비트로 인코딩되므로 $O(nC) = O(n \cdot 2^{\log_2 C})$는 입력 비트 길이에 대해 지수 시간이다. 이를 **유사 다항(pseudo-polynomial)** 이라 부른다. 실행 시간은 $C$의 *값*에 대해서는 다항이지만 *인코딩 길이*에 대해서는 지수이다. 따라서 $C$가 작은(예: $C \leq 10^6$) 현실 문제는 DP로 빨리 풀 수 있어도, $C \approx 2^{100}$이면 그렇지 않다. NP-완비성 증명은 값이 입력 비트 길이에 대해 지수적으로 큰 $C$를 갖는 인스턴스를 구성하며, NP-완비성은 모든 입력 길이에 대한 최악의 경우를 다룬다.

   </details>

6. **2-SAT vs 3-SAT:** 2-SAT는 P에 속하는데 3-SAT는 NP-Complete인 이유는 무엇인가? 둘 사이에서 달라지는 성질은 무엇인가?

   <details>
   <summary>정답</summary>

   **2-SAT**는 함의 그래프로 표현할 수 있다. 절 $(a \lor b)$는 $\overline{a} \implies b$와 $\overline{b} \implies a$와 동치이다. 이 그래프를 만들고 **강결합 요소**를 찾으면(12주차의 Kosaraju 알고리즘), 어떤 변수와 그 부정도 같은 SCC에 속하지 않는지 확인하는 다항 시간 알고리즘을 얻는다. 식은 이 조건이 성립할 때만 만족 가능하다. **3-SAT**에는 이에 대응하는 기법이 알려져 있지 않다. 3절 $(a \lor b \lor c)$는 이진 함의가 아니라 세 선택지 중 하나를 고르는 조건을 나타낸다. 이 추가 자유도가 NP의 **비결정성**을 포착하며, 절에 리터럴이 3개 이상이면 임의의 NP 계산을 인코딩할 수 있다. 경계는 매우 얇으며, 이 추가 자유도가 왜 문제를 NP-Hard로 만드는지 이해하는 것은 계산 복잡도 이론의 깊은 주제이다.

   </details>

7. **간접 최적해를 통한 근사 비율:** $\text{APX} \leq 2 \cdot \text{OPT}$ 증명이 왜 APX를 OPT와 직접 비교하지 않는지, 그리고 간접 경계 $L$이 어떻게 그 대체 역할을 하는지 진술하라.

   <details>
   <summary>정답</summary>

   OPT를 직접 계산할 수 없다는 점이 근사의 핵심이다. 증명에서는 OPT를 직접 구하는 대신 제어 가능한 두 양 사이에 둔다. (1) 최소화 문제에서 $L \leq \text{OPT}$임을 보일 수 있는 다항 시간 계산 가능 경계 $L$, (2) $\text{APX} \leq c \cdot L$을 만족하는 알고리즘 출력 APX이다. 그러면 $\text{APX} \leq c \cdot L \leq c \cdot \text{OPT}$를 얻으며 OPT를 계산할 필요가 없다. 간접 경계 $L$은 핵심 도구이다. 4~8절의 2-근사 증명은 MST 가중치, matching 크기, 부피 한계, 평균 부하, 가상 $(k+1)$번째 중심까지의 거리처럼 서로 다른 경계를 사용한다.

   </details>

8. **TSP 삼각 부등식:** Approx_MST_TSP 증명에서 삼각 부등식은 정확히 어디에 쓰이는가? 삼각 부등식이 없으면 무엇이 잘못되는가?

   <details>
   <summary>정답</summary>

   삼각 부등식은 **알고리즘 Step 3**(shortcut)과 **증명 Step 2**($\text{APX} \leq 2M$)에 쓰인다. DFS 순회의 부분 경로 $x \to y \to z$를 직접 간선 $x \to z$로 바꿀 때 $d(x, z) \leq d(x, y) + d(y, z)$가 필요하다. 이 조건이 없으면 shortcut이 원래 경로보다 *더 길어져* $\text{APX} \leq 2M$ 경계가 깨질 수 있다. **삼각 부등식이 없으면** $P = NP$가 아닌 한 일반 TSP는 어떤 상수 인자로도 근사할 수 없다. 임의의 상수 $\rho$에 대해, HAM-CYCLE 인스턴스 $G$를 $G$의 간선에는 가중치 1을, 그 밖의 간선에는 가중치 $\rho|V| + 1$을 준 TSP 인스턴스로 바꾸면 $\rho$-근사 알고리즘으로 HAM-CYCLE을 판정할 수 있기 때문이다. Metric TSP에서는 삼각 부등식이 shortcut을 안전하게 만든다.

   </details>

9. **Vertex Cover 비율의 tightness:** Maximal matching 알고리즘이 실제로 최적 크기의 *정확히* 2배인 vertex cover를 반환할 수 있음을 보여라(즉 이 알고리즘의 2-경계는 개선할 수 없다).

   <details>
   <summary>정답</summary>

   그래프가 $k$개의 서로 분리된 간선, 즉 끝점을 공유하지 않는 크기 $k$의 perfect matching만으로 이루어진 경우를 생각한다. 최적 vertex cover는 간선마다 한 끝점을 고르므로 크기가 $k$이다. 알고리즘은 $k$개 간선을 모두 maximal matching으로 고르므로 끝점 $2k$개를 반환한다. 비율은 $2k / k = 2.0$으로 **정확히** 2이다. 따라서 이 알고리즘의 2-근사 분석은 tight하며, 이 알고리즘의 근사 비율은 2보다 작게 보장할 수 없다. Vertex cover에서 2보다 나은 비율을 얻으려면 근본적으로 다른 접근이 필요하다. 실제로 어떤 상수 $\epsilon > 0$에 대해서든 $(2 - \epsilon)$-근사를 얻는 것은 Unique Games Conjecture가 참이라는 가정 아래 NP-Hard임이 알려져 있다.

   </details>

10. **Bin Packing First Fit Decreasing (FFD):** First Fit을 적용하기 *전에* 아이템을 크기의 내림차순으로 정렬하면 실전에서 더 좋은 비율을 얻는 이유는 무엇인가? 직관만 쓰고 증명은 필요 없다.

    <details>
    <summary>정답</summary>

    임의 순서의 First Fit은 작은 아이템으로 빈을 일찍 채워, 나중에 온 큰 아이템이 들어갈 자리가 없게 만든다. 그러면 큰 아이템은 거의 빈 새 빈을 따로 차지하게 된다. **내림차순** 정렬은 빈에 공간이 많을 때 큰 아이템을 먼저 놓고, 그 뒤 작은 아이템이 남은 틈을 채우게 한다. 작은 아이템은 바로 이 역할에 적합하다. 점근적으로 FFD는 FF의 $1.7 \cdot \text{OPT}$ 대신 $11/9 \cdot \text{OPT} + O(1)$을 달성한다. 이 직관은 일반화된다. 많은 그리디 근사에서 **덩어리가 큰 아이템을 먼저 처리**하면 작은 아이템이 끝의 채움재 역할을 해 패킹 효율이 크게 향상된다.

    </details>

11. **Job Scheduling의 LPT 개선:** 작업을 **Longest Processing Time First** 순서로 스케줄링하면 $2$ 대신 $4/3$ 근사를 달성하는 이유를 스케치하라.

    <details>
    <summary>정답</summary>

    LPT에서는 makespan을 결정하는 작업 $i$가 더 큰 작업들이 *모두 배치된 뒤에* 할당되므로, 작업 $i$는 상대적으로 작은 작업이다. 두 경우로 나눈다. **경우 A:** $t_i \leq \text{OPT}/3$이면, 2-근사 증명의 부피 한계에서 얻은 $T \leq \text{OPT}$를 재사용해 $\text{APX} = T + t_i \leq \text{OPT} + \text{OPT}/3 = (4/3)\,\text{OPT}$를 얻는다. **경우 B:** $t_i > \text{OPT}/3$이면, 작업 $i$까지(작업 $i$ 포함) 처리된 모든 작업도 크기가 $\text{OPT}/3$보다 크다(LPT가 먼저 처리했으므로 적어도 그만큼 크다). 각 최적 기계는 그런 작업을 최대 두 개만 담을 수 있으므로(세 개면 $\text{OPT}$를 넘는다) 그런 작업은 최대 $2m$개이다. 작업이 $2m$개 이하이고 각 최적 기계가 두 개 이하를 맡는 이런 인스턴스에서는 LPT가 최적 일정을 낸다는 사실이 알려져 있으므로 $\text{APX} = \text{OPT} \leq (4/3)\,\text{OPT}$이다. 어느 경우든 $\text{APX} \leq (4/3)\cdot\text{OPT}$이다. 개념적으로는 큰 작업을 먼저 두면 작은 작업이 끝에서 부하 균형의 여유로 작동하며, 그 단계의 불일치는 덜 중요하다.

    </details>

12. **k-Clustering의 비둘기집 단계:** $\text{OPT} \geq d$ 논증의 비둘기집 단계를 $k = 3$과 가상 중심을 포함한 4개 중심으로 자세히 설명하라.

    <details>
    <summary>정답</summary>

    선택한 $k = 3$개의 중심 $C_1, C_2, C_3$에 가상 중심 $C_4$를 더하면 중심은 모두 4개이다. 최적해는 점을 3개 클러스터로 나눈다. **비둘기집 원리**에 따라 4개 항목을 3개 빈에 나누면 적어도 한 빈에 2개 이상이 들어간다. 즉, 어떤 최적 클러스터는 $\{C_1, C_2, C_3, C_4\}$ 중 적어도 2개를 포함한다. 그 클러스터의 지름은 포함된 두 중심 사이 거리 이상이다. Farthest-first 구성에서 그 거리는 네 중심 사이의 최소 쌍 거리 $d$ 이상이므로 최대 클러스터 지름도 $d$ 이상이고, 따라서 $\text{OPT} \geq d$이다.

    </details>
